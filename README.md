# Calculadora em C

Projeto de uma calculadora simples desenvolvida em linguagem C, com o objetivo de praticar conceitos básicos de programação, operadores matemáticos e estruturas condicionais.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Validação de divisão por zero
- Identificação de operações inválidas

## Tecnologias utilizadas

- Linguagem C
- GCC (compilador)
- Visual Studio Code

## Conceitos aplicados

O projeto utiliza conceitos fundamentais da linguagem C:

- **Variáveis:** `int` e `double`
- **Entrada de dados:** `scanf()`
- **Saída de dados:** `printf()`
- **Estruturas condicionais:** `if`, `else if` e `else`
- **Operadores aritméticos:** `+`, `-`, `*` e `/`

## Como executar

Clone o repositório:

```bash
git clone https://github.com/Lightis4/Calculadora_C.git
```

Entre na pasta:

```bash
cd Calculadora_C
```

Compile o programa:

```bash
gcc Calculado.c -o calculadora
```

Execute no Windows:

```powershell
.\calculadora.exe
```

## Objetivo

Desenvolver a lógica de programação por meio de operações matemáticas simples, utilizando a linguagem C e seus principais recursos.
